# Jadicek Prediction API

FastAPI endpoint untuk dua pipeline LightGBM Jadicek. Buka `/health` untuk status dan kirim `POST /api/predict` untuk inferensi. Model ini merupakan hasil penelitian, bukan diagnosis medis.
