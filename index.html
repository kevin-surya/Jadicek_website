Apakah hasilnya merupakan diagnosis medis?+

Tidak. Hasil model adalah keluaran penelitian dan tidak menggantikan pemeriksaan atau diagnosis tenaga kesehatan.

Mengapa hasil prediksi belum muncul?+

Model di notebook belum diekspor sebagai layanan. Pengelola perlu menghubungkan API prediksi. Selama itu, ringkasan input dan BMI tetap tersedia.

Apakah jawaban saya disimpan?+

Website ini tidak memakai penyimpanan browser atau basis data. Jika API dihubungkan, jawaban akan dikirim ke layanan tersebut; pengelolaan data layanan mengikuti pengaturan penyedia API.
